# 💽 The Sonic Vault & Radar Echo-Safe

**The Sonic Vault** es una plataforma web progresiva diseñada para los verdaderos coleccionistas y exploradores sónicos. Un ecosistema que fusiona el e-commerce de artículos musicales de culto con herramientas de medición acústica en tiempo real y creación musical interactiva.

## ✨ Características Principales

* **Catálogo Dinámico:** Sistema de renderizado de artistas (Eminem, Rihanna, The Weeknd, Lady Gaga, etc.) y eras musicales alimentado por una base de datos local.
* **Desensamblador Sónico:** Reproductores de *stems* ocultos que se activan condicionalmente según la era del artista, permitiendo desglosar los elementos de una pista.
* **Radar Echo-Safe (Mapa de la Tranquilidad):** Una herramienta de impacto social construida con `React-Leaflet`. Utiliza la Geolocation API y la Web Audio API para medir decibelios del entorno, categorizar el ruido y trazar un mapa colaborativo.
* **Estudio "BEAT IT" (MPC Interactivo):** Un módulo avanzado de creación musical. Utiliza la Web Audio API nativa para generar síntesis de sonido en tiempo real con envolventes ADSR, polifonía, grabación de loops (looper) y un osciloscopio dinámico renderizado en Canvas.

## 🛠️ Stack Tecnológico

El proyecto opera bajo una arquitectura moderna basada en componentes, con un enfoque en la calidad del código y la automatización:

* **Frontend:** React.js
* **Build Tool:** Vite (Optimización de desarrollo y HMR)
* **Audio & Gráficos:** Web Audio API & HTML5 Canvas
* **Mapas & Geoposicionamiento:** Leaflet & React-Leaflet
* **Estilos:** CSS3 puro con variables y temática Dark/Neon (UI Glassmorphism)
* **Testing & Documentación:** Vitest, React Testing Library y JSDoc.
* **Versionamiento:** Git & GitHub (Flujo de trabajo estricto basado en GitFlow y gestión de Issues)

## 🚀 Instalación y Ejecución Local

Para correr este proyecto en tu entorno local:

1. Clona este repositorio.
2. Abre la terminal en la raíz del proyecto.
3. Instala las dependencias necesarias:
   ```bash
   npm install
    ```

4. Inicia el servidor de desarrollo:

   ```bash
   npm run dev
    ```
